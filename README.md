# 🛒 Shopping List - React & TypeScript

### 📝 Description
A dynamic shopping list application built to master React's core concepts. The main focus of this project was implementing complex state management using `useState` and understanding data flow through **Prop Drilling**. It allows users to create a precise shopping list with specific units (kg, g, l, ml) and see real-time updates as they type.

> **Mobile First:** Unlike my previous projects, this one was built with a **Responsive Web Design** approach using Tailwind CSS, making it fully functional on both mobile and desktop devices.

### ✨ Key Features & Learning Goals
* **State Management:** Advanced use of `useState` to handle dynamic lists and input forms.
* **Prop Drilling:** Practiced passing data and functions through multiple layers of components to understand component architecture.
* **Unit Selection:** Custom logic to toggle between weight (kg, g) and volume (l, ml) units.
* **Responsive Design:** Styled with Tailwind CSS for a seamless experience on all screen sizes.
* **Type Safety:** Built with TypeScript to ensure robust code and catch potential errors during development.
